# Bunny Digital Clock 🐰

크림색 토끼 귀와 7세그먼트 디지털 숫자를 결합한 감성 시계입니다.

## 기능
- 현지 시간, AM/PM, 날짜 표시
- SVG 기반 7세그먼트 숫자
- 위치 권한을 허용하면 Open-Meteo에서 현재 날씨 조회
- 맑음은 햇살, 비는 빗줄기, 흐림은 구름빛, 눈은 눈송이 배경 효과
- 날씨 API 실패 시에도 시계는 정상 작동
- 모바일 반응형 및 움직임 감소 설정 지원

## 로컬 실행
JavaScript 모듈을 사용하므로 파일을 직접 여는 대신 VS Code Live Server 같은 정적 서버로 프로젝트 루트를 실행하세요.

## GitHub Pages
1. 모든 파일을 저장소 루트에 업로드합니다.
2. Settings → Pages로 이동합니다.
3. Deploy from a branch, `main`, `/ (root)`를 선택합니다.
4. HTTPS로 배포된 페이지를 열고 `날씨 연결`을 눌러 위치 권한을 허용합니다.

위치 권한이나 인터넷 연결이 없어도 기본 시계는 작동합니다.
